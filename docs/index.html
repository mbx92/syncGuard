SyncGuard — Dokumentasi Sistem

Manajer backup NAS berbasis web · Agent portable Windows · Hub terpusat

Agent :7432 Hub :7443 Rsync · Robocopy · MinIO PostgreSQL

Ringkasan

SyncGuard adalah aplikasi manajemen backup yang memungkinkan Anda menjalankan banyak job backup dari satu dashboard web. Mendukung sinkronisasi ke Synology NAS (SSH/rsync), share SMB (Robocopy), dan object storage MinIO/S3.

KemampuanDetail
Multi-jobBanyak job dengan jadwal cron atau manual
Real-timeProgress & log via WebSocket
PostgreSQLpg_dump + upload ke NAS/MinIO
HubMonitor banyak agent dari satu dashboard
PortableNode.js + cwRsync bundled di Windows

Alur job backup

  1. Trigger — cron, Run Now, atau perintah remote dari Hub
  2. Validasi — engine, kredensial, binary (rsync, pg_dump, mc)
  3. Eksekusi — filesystem langsung sync; PostgreSQL: dump lalu sync/upload
  4. Log — ke logs/{jobId}.log + broadcast WebSocket
  5. Hub — status & log summary dikirim jika Hub aktif

Instalasi

Windows Portable (disarankan)
  1. Jalankan setup-portable.bat
  2. Buka http://localhost:7432

Tidak perlu install Node.js jika tools/node/ ikut di-copy.

Linux (systemd)

npm install --omit=dev
chmod +x scripts/linux/*.sh
sudo ./scripts/linux/install-agent-service.sh \
  --user syncguard --app-dir /opt/syncguard --port 7432

Hub lokal / Docker

npm run hub:install && npm run hub:build && npm run hub
# atau
start-hub-docker.bat

Konfigurasi Agent

File utama: config/config.json (lokal, tidak di-commit).

NAS / SSH (Rsync)

FieldKeterangan
IP AddressIP Synology/NAS
SSH UserUser SSH (mis. cwrsync)
SSH PortDefault 22 atau custom 2222
Base Backup PathPath di NAS, mis. /volume1/backup
SSH Key wajib untuk backup rsync di Windows. Setelah ganti password Synology: isi password baru → Save → Deploy SSH Key ulang. Key ada di config/keys/syncguard_ed25519.

Robocopy (SMB)

SMB Share Path: \\192.168.1.100\backup. Exit code 0–7 = sukses.

MinIO

FieldKeterangan
EndpointURL MinIO/S3
Bucket NameWajib — klik Save MinIO Config

Path upload: s3://{bucket}/{prefix}/{nama-job}/{file}

SyncGuard Hub (di agent)

Enabled, Hub URL (URL publik), Agent ID, API Key dari Hub → Settings.

Jenis Job

Filesystem (folder sync)

  • Source Path — folder lokal
  • Dest Path — opsional override di NAS
  • Exclusions — pola skip (mis. node_modules, .git)
  • Schedule — cron atau manual

PostgreSQL

  1. Fase dump — pg_dump → file ber-timestamp
  2. Fase sync — rsync ke NAS atau mc cp ke MinIO
Setiap run membuat file dump baru. File lama di NAS tidak menghalangi run manual. Job terjadwal dan Run Now tidak saling memblokir.

SyncGuard Hub

Dashboard pusat di port 7443 untuk memantau banyak agent, melihat history run/log, dan mengirim perintah remote.

Mendaftarkan Agent

  1. Hub → Settings → buat agent → salin API Key
  2. Di agent → Settings → SyncGuard Hub: Enabled, URL, Agent ID, API Key
  3. Simpan & restart agent

Deploy Docker/Coolify

  • Dockerfile: docker/hub/Dockerfile
  • Volume: /data (persistent)
  • Env: HUB_ADMIN_TOKEN, HUB_PUBLIC_URL
  • Health: GET /api/v1/health

Keamanan

  • Jangan commit config/config.json — berisi password & key
  • Ganti default admin token Hub (Admin123!) di production
  • Gunakan HTTPS untuk Hub di internet
  • Home directory user SSH Synology: permission 755, bukan 777
  • Rotate Agent API Key jika bocor
