Robocopy Setup Guide

Robocopy sudah built-in di Windows — tidak perlu install tambahan.

1. Aktifkan SMB di Synology

Control Panel → File Services → SMB → Enable SMB service

2. Buat shared folder

Control Panel → Shared Folder → buat folder backup

3. Set SMB Share Path

\\192.168.1.100\backup

4. Akses dari Windows

net use Z: \\192.168.1.100\backup /user:admin password
(atau map drive lewat File Explorer)

Rsync Setup Guide

Untuk menjalankan rsync di Windows, pilih salah satu cara:

1. WSL (Windows Subsystem for Linux) — Recommended

Rsync Path: wsl rsync

2. cwRsync (standalone)

Download dari itefix.net/cwrsync, lalu set path ke C:\cwrsync\bin\rsync.exe

SSH Key (tanpa password prompt)

ssh-keygen -t ed25519 -C "syncguard"
ssh-copy-id admin@192.168.1.100
